# Настройка физики

Параметры находятся в `src/constants.rs`. Уровни сохраняют блок размером 80
единиц; исходные 30 единиц Geometry Dash умножаются на `GD_SCALE`.
`GD_VELOCITY_UNIT` переводит внутреннюю вертикальную скорость в единицы/с.
При изменении скорости сохраняется округление до 0,001 исходной единицы.

| Поведение | Параметры |
| --- | --- |
| Частота физики | `HZ`, `DT` — независимо от FPS |
| Горизонтальная скорость | `SPEED` |
| Куб | `JUMP`, `GRAVITY`, `MAX_FALL_SPEED`, `CUBE_ROTATION_*` |
| Корабль | `SHIP_GRAVITY`, `SHIP_MAX_RISE_SPEED`, `SHIP_MAX_FALL_SPEED`, `SHIP_ROTATION_LERP` |
| Волна | `WAVE_SPEED`, `WAVE_ANGLE`, `WAVE_ROTATION_LERP` |
| Робот | `ROBOT_JUMP`, `ROBOT_GRAVITY`, `ROBOT_HOLD`, `ROBOT_HOLD_GRAVITY_FACTOR` |
| Шар и паук | `BALL_*`, `SPIDER_*` |
| Орбы и пады | `ORB_JUMP_FORCE`, `JUMP_PAD_*_FORCE` |
| Масштаб и камера | `VIEWPORT_HEIGHT`, `GAME_CAMERA_Y`, `PLAYER_SCREEN_X`, `CAMERA_FOLLOW_SPEED` |
| Границы | `GROUND_HEIGHT_FOR_*`, `CEILING` |

У корабля ускорение зависит от вертикальной скорости и удержания кнопки.
Эту зависимость задаёт `ship_acceleration`; одной константы тяги недостаточно.
Перемещение Y выполняется один раз за тик. У волны вертикальная скорость равна
горизонтальной; деления на квадратный корень из двух нет.

Свежий прыжок куба: 103 тика, 0,429167 с, дальность 356,586124 и высота 170,2584.
Повторный прыжок при удержании начинается по другому пути обработки ввода и
сохраняет один дополнительный шаг гравитации. Не убирайте это различие при
рефакторинге. Тест сравнивает движение со снятыми координатами Steam-оригинала.

Проверить параметры без окна:

```sh
cargo run --no-default-features --example physics_probe
cargo run --no-default-features --example physics_probe -- --stereo
cargo test --no-default-features
```

Область проверки, ссылки на реконструкции оригинала и оставшиеся отличия описаны
в [physics.md](physics.md). Подбор констант не заменяет проверку столкновений,
порталов и особенностей старых версий физики.
